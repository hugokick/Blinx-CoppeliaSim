# V1-03 物体定位与旋转角测量

## 实验目标

在 CoppeliaSim 视觉质检场景中定位三个彩色标准件，读取图像中心、旋转框和
方向角。学生应能解释图像坐标系、旋转矩形和角度归一化，并识别没有唯一方向
的圆形和近方形目标。

## 安全边界

程序只调用公开 SDK 和无参数 `ctx.vision2d.analyze()`。ROI、阈值和算法参数
由实验定义发布，学生不能传入文件、对象路径或 Remote API 参数。本实验只
计算图像坐标，不下发真实机械臂定位、旋转、抓取或放置命令。

算法层使用原创合成图验证中心和角度规则；正式课程使用 CoppeliaSim 图像。
在线仿真证据不能替代真实相机标定和机器人手眼标定。

## 统一入口

- PyQt：运行 `run_pyqt.ps1` 后在“实验目录”选择 `V1-03`；
- CLI：`experiment-run --experiment V1-03 --port 23005`；
- 通用包装器注册后：
  `.\tools\vision_lab\run_experiment.ps1 -Experiment V1-03 -Port 23005`。

静态测试中的在线 skip 不是 PASS；正式在线结论必须来自显式 CoppeliaSim
运行及其 JUnit 和结果包。

## 发布配置与角度语义

实验固定使用 `standard` 512 × 512 配置和
`[180, 180, 335, 340]` 原图 ROI，不发布毫米比例尺。结果包括：

- `center_px`：轮廓矩的图像中心；
- `rotated_box_px`：最小旋转包围框的四个顶点；
- `angle_deg`：归一化到统一范围的长边角度；
- `quality_flags`：没有唯一定义或存在方向歧义的说明。

圆形的 `angle_deg` 必须为空，并带 `ANGLE_UNDEFINED_FOR_CIRCLE`。近方形可带
`ANGLE_AMBIGUOUS_FOR_SQUARE`，提醒学生方形旋转 90° 后外观等价。

## 学生步骤

1. 读取实验信息并确认 `analysis_focus=pose`；
2. 应用发布的 `standard` 配置；
3. 调用一次受控二维分析；
4. 确认三个目标的中心和旋转框字段完整；
5. 对圆形检查空角度和对应质量标志；
6. 对其他目标记录角度，并解释方形或近方形的方向歧义；
7. 留下 checkpoint，最后在 `finally` 中恢复基线配置。

## 五层证据

结果包包含 `raw`、`roi-input`、`foreground-mask`、`cleaned-mask` 和
`annotated` 五层。标注图显示检测 ID、轮廓和中心；结构化 JSON 保存旋转框、
角度和质量标志。图层路径、尺寸和 SHA-256 用于复核，不是课程成绩。

## automated checks

- `standard_profile`：分析和复位使用发布配置；
- `three_targets`：检测到三个标准件；
- `pose_fields`：中心、旋转框和非圆形角度字段有效；
- `angle_semantics`：圆形角度为空且质量标志正确；
- `five_layer_evidence`：五层证据及其哈希完整。

## human checks

- 学生能够解释中心、旋转框和角度归一化；
- 学生能够解释圆形无方向以及方形角度歧义。
