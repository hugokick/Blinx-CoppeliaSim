# R1-02 机械臂示教和运动控制

## 实验任务

按固定顺序访问四个示教点，在每个命令边界使用暂停、继续和单步观察运动，理解确定性运动序列和安全抬升规则。

## 实验入口

V2.1 与课程目录集成后，可在 PyQt“实验目录”选择 `R1-02`，载入 `student_programs/templates/r1_02_teach_points.py`；命令行入口为 `experiment-run --experiment R1-02`。当前并行资产分支不实现 CLI、Controller 或 PyQt 接入。

## 原理

示教点是世界坐标中的目标位置。受控运行器在命令边界处理暂停和单步，一次单步只放行一条后续命令。低位横移可能碰撞工作台或工件，因此横向移动必须在安全高度进行；速度仍受主进程策略约束。

## 操作步骤

1. 核对 `/RobotBasics/TeachPoints/TeachPoint1` 至 `TeachPoint4`。
2. 阅读 `teach_points_mm` 的顺序和单位。
3. 回零后开始运行，在第一个 checkpoint 暂停。
4. 使用“下一步”逐条放行至少两条命令，观察状态变化。
5. 继续运行到第四个示教点，再安全返回 home。

## 完成条件

- 四个示教点均按清单顺序到达；
- 产生四个 checkpoint；
- 无越界、超速或低空横移拒绝；
- 停止或正常结束后吸盘关闭且回到安全状态；
- 教师确认学生理解命令边界。

## 常见错误

- 误以为暂停能中断已经进入底层执行的单条运动；
- 调换 X、Y、Z 或遗漏 `speed`；
- 在低位直接从一个示教点横移到另一个；
- 把一次单步理解为运行到下一个循环结束。

## 仿真与真机差异

本实验当前只完成软件与 CoppeliaSim 仿真验证，硬件状态为 PENDING_HARDWARE。仿真 PASS 不代表真机验收通过；真实相机噪声、机械臂误差、急停、气路和物理抓取需在 V2.3 单独验收。

## 结果保存

集成运行后保存 `source.py`、`manifest.json`、命令与事件记录、`scene-initial.json`、`scene-final.json` 和 `summary.json`。说明每个 checkpoint 对应的示教点；本实验没有相机调用时可无 `snapshots.jsonl`。

## 人工验收点

- 学生能解释为何低空不能横移；
- 学生能区分暂停、继续、单步和停止；
- 学生能根据命令记录复述四点运动顺序。
