# R1-01 机械臂认知和基础操作

## 实验任务

在机器人基础场景中识别六个关节、工具中心点（TCP）和工作空间，执行回零、读取位姿、移动到观察位并安全返回 home。学生需要把“看到机械臂运动”和“理解坐标与安全边界”结合起来。

## 实验入口

在 PyQt“实验目录”选择 `R1-01`，载入 `student_programs/templates/r1_01_robot_basics.py`；命令行使用 `python -m vision_platform.cli experiment-run --experiment R1-01`。这些是统一使用入口；本文的入口说明不构成 CoppeliaSim 在线验收，实际状态必须以单独在线测试证据为准。

## 原理

六轴机械臂由串联关节链构成，TCP 是末端工具执行运动任务时使用的参考点。本实验使用世界坐标系中的毫米位置，保持一期 position-only 控制合同，不开放姿态和关节角直接控制。回零给出可重复初态，安全高度用于降低横向碰撞风险。

## 操作步骤

1. 打开 `BL23_robot_basics.ttt`，确认 `/RobotBasics` 与六个关节路径存在。
2. 阅读模板，标出 `home()`、`pose()`、`move_world()` 和 `checkpoint()`。
3. 运行程序，记录回零后的 TCP。
4. 在观察位暂停，现场指出六个关节和 TCP。
5. 继续运行并确认机械臂返回 home。

## 完成条件

- 程序的软件状态为 PASS；
- 存在初态与末态检查记录；
- 命令轨迹包含回零、位姿读取和观察位移动；
- 结束时机械臂返回 home，吸盘保持关闭；
- 教师完成人工检查，硬件状态不改变。

## 常见错误

- 把关节坐标、世界坐标和 TCP 坐标混为一谈；
- 将毫米参数误写为米；
- 在低于安全高度时横向移动；
- 看到仿真运动后直接推断真实机械臂也能安全执行。

## 仿真与真机差异

本实验当前只完成软件与 CoppeliaSim 仿真验证，硬件状态为 PENDING_HARDWARE。仿真 PASS 不代表真机验收通过；真实相机噪声、机械臂误差、急停、气路和物理抓取需在 V2.3 单独验收。

## 结果保存

集成运行后保存 `source.py`、`manifest.json`、`scene-initial.json`、`scene-final.json` 和 `summary.json`；无相机调用时可以没有 `snapshots.jsonl`。记录应保留实验 ID、场景哈希和 `PENDING_HARDWARE`。

## 人工验收点

- 学生能现场指出六个关节与 TCP；
- 学生能解释世界坐标、home 和安全高度；
- 学生能解释 `PENDING_HARDWARE` 的含义；
- 学生能说明软件/仿真证据不能代替真机验收。
