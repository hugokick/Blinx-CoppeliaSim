# V1-06 固定模板匹配与视觉证据

## 实验目标

在 CoppeliaSim 视觉质检场景中，用受控 SDK 查询固定模板在相机图像中的位置，理解模板、搜索区域、`TM_CCOEFF_NORMED` 相似度、阈值和像素坐标。实验同时练习读取三层证据包：`raw`、`template`、`annotated`。

## 安全边界

学生程序只调用公开 SDK，不导入 OpenCV、CoppeliaSim Remote API 或本机文件。模板、ROI、阈值、版本和资产哈希由主机清单固定，命令不接受参数。本实验是只读视觉认知实验，不执行移动、抓取、吸取或任意动作。

仿真结果不能证明海康相机的真实光学精度、材质泛化、真实机械臂动作或物理抓取效果。

## 统一入口

- PyQt：“实验目录”选择 `V1-06`；
- CLI：`experiment-run --experiment V1-06 --port 23005`；
- 专用包装器：`.\tools\vision_lab\run_v1_06_template_matching.ps1`（默认端口 `23005`）；
- 通用包装器：`.\tools\vision_lab\run_experiment.ps1 -Experiment V1-06 -Port 23005`。

在线验收必须显式连接 CoppeliaSim；静态测试中的 skip 不是在线 PASS。

## 学生步骤

1. 读取实验信息，确认模板 ID、版本、方法、阈值和搜索区域；
2. 使用 `standard` profile，调用 `ctx.vision2d.template_match()`；
3. 观察 `matched`、`score`、`bbox_px`、`center_px` 和 `image_size`；
4. 对照 `raw`、固定 `template` 与 `annotated` 图层，说明坐标为何在原图坐标系中；
5. 解释阈值改变会造成的“匹配/未匹配”边界，但不能修改发布配置；
6. 保存 checkpoint 和证据包，最后恢复基线 profile。

## 结果字段

- `schema_version`：公共结果协议版本，当前为 `1`；
- `template_id`、`template_version`：经主机清单校验的模板身份；
- `matched`、`status`：相似度是否达到固定阈值；
- `score`、`threshold`：有限的归一化相关分数与阈值；
- `bbox_px`、`center_px`：原始图像坐标中的模板框和中心；
- `search_roi_px`、`method`：固定搜索窗口和算法名称。

结果包还记录每层 PNG 的路径、尺寸和 SHA-256，用于复核本次运行，不是课程成绩。

## automated checks

- `standard_profile`：使用并恢复发布 profile；
- `template_asset_binding`：模板清单、尺寸和哈希一致；
- `template_match_fields`：结果字段和坐标合同完整；
- `three_layer_evidence`：`raw`、`template`、`annotated` 三层可复核。

## 人工与硬件边界

教学效果保持 `PENDING_HUMAN_ACCEPTANCE`。海康相机、真实机械臂、急停、气路、物理抓取和真实光学精度保持 `PENDING_HARDWARE`。CoppeliaSim 在线通过只证明虚拟视觉链路。
