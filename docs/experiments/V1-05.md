# V1-05 颜色、形状与轮廓识别

## 实验目标

在 CoppeliaSim 视觉质检场景中使用 HSV 颜色信息和轮廓几何识别三个彩色
标准件，读取颜色、形状、顶点数、圆度、长宽比和轮廓点。学生应理解阈值、
光照、轮廓近似和 `unknown` 标签的边界。

## 安全边界

学生程序只调用公开 SDK，不直接导入 OpenCV、旧识别模块或 CoppeliaSim
Remote API。受控命令不接受自定义文件、ROI、阈值或路径。本实验不执行分类
抓取、机械臂运动或吸盘动作。

算法层使用原创合成图验证颜色和形状规则；正式课程使用 CoppeliaSim 图像。
仿真标签不能证明真实光照、材质、反射、相机色彩或真实识别准确率。

## 统一入口

- PyQt：“实验目录”选择 `V1-05`；
- CLI：`experiment-run --experiment V1-05 --port 23005`；
- 通用包装器注册后：
  `.\tools\vision_lab\run_experiment.ps1 -Experiment V1-05 -Port 23005`。

在线验收必须显式连接 CoppeliaSim；静态 skip 不是 PASS。

## 识别字段

- `color`：HSV 中位色相与饱和度规则产生的标签；
- `shape`：轮廓近似顶点、圆度和长宽比产生的标签；
- `vertex_count`：近似多边形顶点数；
- `contour_px`：原图坐标下的轮廓点；
- `circularity`、`aspect_ratio`：辅助解释形状的数值；
- `quality_flags`：角度未定义或存在歧义等边界提示。

无法可靠归类时必须保留 `unknown`，不得强行映射到最相近的已知颜色或形状。

## 学生步骤

1. 读取实验信息并确认 `analysis_focus=appearance`；
2. 应用 `standard`，执行一次受控分析；
3. 检查三个目标的颜色、形状、顶点和轮廓字段；
4. 对照 `raw`、掩膜和 `annotated` 解释识别过程；
5. 记录圆度和长宽比，但不把单一阈值当作通用准确率；
6. 如出现 `unknown`，保留标签并分析饱和度、色相或轮廓原因；
7. 留下 checkpoint，最终恢复基线配置。

## 五层证据

结果包包含 `raw`、`roi-input`、`foreground-mask`、`cleaned-mask` 和
`annotated` 五层图像，以及完整颜色、形状和轮廓 JSON。路径、尺寸和 SHA-256
用于复核这一次仿真运行，不是课程成绩。

## automated checks

- `standard_profile`：使用并恢复发布配置；
- `three_targets`：正式场景检测到三个标准件；
- `appearance_fields`：颜色、形状、顶点、轮廓和比率字段完整；
- `unknown_preserved`：未知标签不会被静默改写；
- `five_layer_evidence`：图像层和结构化结果可复核。

## human checks

- 学生解释 HSV 阈值、饱和度和光照变化的影响；
- 学生解释轮廓近似、圆度、长宽比与 `unknown` 标签。

人工教学检查为 `PENDING_HUMAN_ACCEPTANCE`。自动状态不是课程成绩。

## 验收与硬件边界

CoppeliaSim 在线通过只证明虚拟识别链路。海康相机、真实机械臂、真实材质
泛化、急停、气路、物理抓取和真实识别准确率保持 `PENDING_HARDWARE`。
