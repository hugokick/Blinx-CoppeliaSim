# R1-06 基于视觉的数字排序

## 实验任务

识别原创七段式数字 1、2、3，按升序放入三个目标槽位；扩展练习把业务规则切换为 3、2、1，而不改动感知与运动安全合同。

## 实验入口

在 PyQt“实验目录”选择 `R1-06`，载入 `student_programs/templates/r1_06_digit_sort.py`；命令行使用 `python -m vision_platform.cli experiment-run --experiment R1-06`。场景任务组为 `/LogisticsLab/Tasks/Digits`。这些是统一使用入口；本文的入口说明不构成 CoppeliaSim 在线验收，实际状态必须以单独在线测试证据为准。

## 原理

数字候选区域与正式参考图使用同一套归一化流程：提取深色前景，裁到紧致包围框，归一到七段拓扑窗口并居中到带留边的 64×96 黑底画布，再进行模板匹配。这样由七段结构而不是白色底板面积主导分数。识别结果给出类别、位置和 `confidence`；共享视觉合同要求 `confidence >= 0.5`，低于 0.5 时停止。排序规则决定类别到目标槽的映射；缺失、重复或低可信结果均不得触发运动。

## 操作步骤

1. 检查标签清单的生成器、`project-original-generated` 标记和 SHA-256。
2. 激活 Digits 任务组并采集相机快照。
3. 对三个候选区域归一化并完成模板匹配。
4. 确认类别集合恰为 1、2、3 后，按升序执行抓取和放置。
5. 扩展练习改用 `reverse_order`，重新复位场景后验证倒序。

## 完成条件

- 三个数字均被识别且没有重复映射；
- 基础模式按 1、2、3 放入对应槽位；
- 扩展模式能明确切换为 3、2、1；
- 终态场景探针记录 `matched=3`；
- 识别不完整时不下发抓取命令。

## 常见错误

- 参考图读取失败但仍继续计算；
- 未归一化尺寸就直接比较；
- 直接比较整块白色底板，使背景面积主导匹配分数；
- 把识别顺序误当成业务排序；
- 同一数字覆盖字典中的另一个候选；
- 修改槽位而未先复位场景。

本实验当前只完成软件与 CoppeliaSim 仿真验证，硬件状态为 PENDING_HARDWARE。仿真 PASS 不代表真机验收通过；真实相机噪声、机械臂误差、急停、气路和物理抓取需在 V2.3 单独验收。

集成运行后保存 `source.py`、`manifest.json`、`snapshots.jsonl`、原始快照、各数字匹配置信度、`scene-initial.json`、`scene-final.json` 和 `summary.json`。升序与倒序运行应使用不同证据目录。

## 人工验收点

- 学生能解释归一化和模板匹配；
- 学生能把升序切换为倒序并说明只改变了业务规则；
- 学生能说明识别集合不完整时为何必须停止。
