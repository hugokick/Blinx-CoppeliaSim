# V1-09 构件表面缺陷检测与合格/缺陷分流

本实验使用独立的 `BL23_vision_defect_sorting_lab.ttt` 场景。画面包含一个
reference 参考件和六个固定 candidate ROI；学生程序只调用
`ctx.vision2d.surface_defects()` 获取主机冻结的六条目计划，再用
`ctx.vision2d.defect_sort_entry(entry_id)` 逐条申请受控执行。

固定检测配置由课程定义绑定：图像为 1024×1024，reference 和六个 candidate
ROI 均为 192×192，缺陷判断使用缺失、孔洞、异物、破损和尺寸五类决策。程序
不能提交路径、图片、ROI、阈值、坐标、速度、槽位或 raw robot/tool 命令；检测
失败、证据不一致、探针失败或停止都会 fail closed，且不会消费条目。

结果面板同时显示原图、参考件、选中候选件、检测标注和“缺陷区域示意”。示意
掩膜只由 detector 已发布的 finding bbox 绘制，不代表工业像素级分割真值。每个
条目在同一次运行中先做起始位探针，动作结束后再做目标槽探针，确认后才生成
回执；暂停、单步、继续、停止和受控 reset 均保留在运行器安全边界内。

实验仍保留 `PENDING_HUMAN_ACCEPTANCE` 与 `PENDING_HARDWARE`。静态测试或
CoppeliaSim 证据不等同于真实海康相机、真实机械臂、急停、气路、物理抓取或
教学效果验收。
