# R1-07 基于视觉的水果与构件分类

## 实验任务

把原课程的水果分类学习目标工程化为构件分仓：识别红方块、蓝方块、绿圆柱和黄圆柱，并按配置映射到四个目标仓位。

## 实验入口

在 PyQt“实验目录”选择 `R1-07`，载入 `student_programs/templates/r1_07_component_sort.py`；命令行使用 `python -m vision_platform.cli experiment-run --experiment R1-07`。场景任务组为 `/LogisticsLab/Tasks/Classes`。这些是统一使用入口；本文的入口说明不构成 CoppeliaSim 在线验收，实际状态必须以单独在线测试证据为准。

## 原理

HSV 色相用于区分红、蓝、绿、黄，轮廓圆度用于区分方块与圆柱，二者组合成稳定类别 ID。类别 ID 再由配置映射到仓位。共享视觉合同要求 `confidence >= 0.5`；低于 0.5、视觉输出为空、类别集合不完整或出现未知类别时，程序必须停止，不能猜测后继续抓取。

## 操作步骤

1. 激活 Classes 任务组并确认其他任务组不在相机工作区。
2. 采集快照，生成颜色、形状、像素中心、世界坐标和置信度记录。
3. 核对类别集合与配置中的四类完全一致。
4. 逐个执行安全抓取和分仓，并记录 checkpoint。
5. 检查四个目标仓位和安全收尾状态。

## 完成条件

- 四类构件均被识别且无未知类别；
- 每个类别按照配置路由到唯一仓位；
- 终态场景探针记录 `matched=4`；
- 空结果或类别不完整时没有运动命令；
- 完成或失败后吸盘关闭并回到安全状态。

## 常见错误

- 红色色相跨越 0/179 边界时阈值不完整；
- 轮廓被遮挡导致圆度判断错误；
- 类别字符串与配置键不一致；
- 低置信度结果仍触发抓取；
- 把仿真中的纯色几何体效果等同于真实水果或真实构件。

## 仿真与真机差异

本实验当前只完成软件与 CoppeliaSim 仿真验证，硬件状态为 PENDING_HARDWARE。仿真 PASS 不代表真机验收通过；真实相机噪声、机械臂误差、急停、气路和物理抓取需在 V2.3 单独验收。

## 结果保存

集成运行后保存 `source.py`、`manifest.json`、`snapshots.jsonl`、原始快照、分类结果、`scene-initial.json`、`scene-final.json` 和 `summary.json`。分类结果应保留颜色、形状、置信度和路由仓位。

## 人工验收点

- 学生能解释颜色与形状特征如何组合成类别；
- 学生能说明空结果或低置信度时为何必须停止；
- 学生能指出仿真纯色几何体与真实构件成像的差异。
