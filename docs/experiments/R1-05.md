# R1-05 基于视觉的物体码垛

## 实验任务

从物流场景快照中识别六个彩色块体，把像素中心转换为世界坐标，并按两列三层的顺序完成放置。实验重点是视觉结果、业务顺序和安全运动共同形成闭环。

## 实验入口

V2.1 与课程目录集成后，可在 PyQt“实验目录”选择 `R1-05`，载入 `student_programs/templates/r1_05_visual_stacking.py`；命令行入口为 `experiment-run --experiment R1-05`。场景任务组为 `/LogisticsLab/Tasks/Stack`。

## 原理

模板使用 HSV 饱和度掩膜提取彩色物体，通过轮廓矩计算像素中心，再使用 2×3 仿射矩阵换算世界坐标。抓取流程遵循“安全高度到达—垂直下降—吸附—垂直抬升—安全高度横移—下降释放—再次抬升”。堆叠顺序决定结构稳定性。

## 操作步骤

1. 激活 Stack 任务组，确认 Digits 和 Classes 任务组隔离。
2. 采集 `/LogisticsLab/Camera` 快照，检查识别数量是否为 6。
3. 核对每个像素中心转换后的世界坐标是否落在拾取区。
4. 按 `stack_slots_mm` 顺序逐块抓取和放置。
5. 每放置一块记录 checkpoint，最后回到 home。

## 完成条件

- 相机快照可追溯且识别到六个待码垛物体；
- 所有运动经过安全高度；
- 六个目标位置形成两列三层；
- 终态检查记录六个匹配项；
- 停止、失败或完成后吸盘关闭。

## 常见错误

- HSV 阈值把灰色工作台识别为目标；
- 仿射矩阵方向或像素坐标顺序写反；
- 未检查识别数量就启动运动；
- 先放上层导致结构不稳定；
- 为了通过仿真而放宽真实工作空间或吸盘距离。

## 仿真与真机差异

本实验当前只完成软件与 CoppeliaSim 仿真验证，硬件状态为 PENDING_HARDWARE。仿真 PASS 不代表真机验收通过；真实相机噪声、机械臂误差、急停、气路和物理抓取需在 V2.3 单独验收。

## 人工验收点

- 学生能解释 HSV 参数与漏检、误检的关系；
- 学生能手算一个像素点到世界坐标的转换；
- 学生能说明两列三层的放置顺序与安全抬升原因。
