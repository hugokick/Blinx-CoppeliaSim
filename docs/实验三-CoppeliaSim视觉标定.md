# 实验三：CoppeliaSim 视觉标定

## 实验任务

使用 CoppeliaSim 顶视虚拟相机和三个拟合标记建立像素坐标到机器人世界坐标的二维仿射变换，再用第四个独立标记验证误差。学生需要得到可保存、可复现、可判断是否合格的标定结果。

## 实验入口

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File tools\vision_lab\run_pyqt.ps1
```

教学界面打开后，确认“相机=sim、机器人=sim、连接正常”，再进入标定操作。

## 原理

平面上的像素点 \((u,v)\) 与世界坐标 \((x,y)\) 用仿射矩阵关联：

\[
\begin{bmatrix}x\\y\end{bmatrix}
=
\begin{bmatrix}
a_{11}&a_{12}&b_1\\
a_{21}&a_{22}&b_2
\end{bmatrix}
\begin{bmatrix}u\\v\\1\end{bmatrix}
\]

三个不共线点可确定六个参数。场景另设一个不参与拟合的验证点，用于发现点序错误、轴交换和镜像错误。合格阈值为 RMS 不大于 3 mm、最大误差不大于 5 mm。

## 操作步骤

1. 启动界面并连接 CoppeliaSim。
2. 检查相机画面中三个白色拟合标记和一个品红验证标记是否可见。
3. 点击“标定”，等待界面输出四个标记的像素坐标和世界坐标。
4. 检查拟合点数量为 3、验证点数量至少为 1。
5. 查看 RMS 和最大误差。
6. 检查坐标方向：本场景中世界 X 增大对应像素 X 减小，世界 Y 增大对应像素 Y 增大。
7. 保存标定结果和叠加图。
8. 重新运行一次标定，比较两次误差和矩阵是否稳定。

## 完成条件

- 三个拟合标记全部识别；
- 至少一个独立验证标记参与误差计算；
- RMS ≤ 3 mm；
- 最大误差 ≤ 5 mm；
- 没有 X/Y 轴交换或镜像；
- `calibration.json` 和标定叠加图均已保存。

## 常见错误

- 标记不全：检查 CoppeliaSim 是否已开始仿真、CameraRenderScope 是否生效。
- RMS 很小但坐标方向错误：通常是对称点顺序或 X/Y 轴交换，必须检查独立验证点和矩阵符号。
- 相机画面为空：检查 23000 端口、场景路径和虚拟相机路径 `/VisionLab/Camera`。
- 使用旧标定文件：删除本次输出目录中的旧结果后重新标定。
- 把 RX/RY/RZ 当成标定量：本实验只标定平面 X/Y，末端姿态不参与。

## 仿真与真机差异

仿真相机没有镜头畸变、曝光波动、安装松动和网络丢帧。真实海康相机必须重新完成 MVS 枚举、曝光/触发设置和真实三点标定，不能复制仿真矩阵。真实工作台高度变化还会影响抓取 Z 和 TCP 偏差。

## 结果保存

默认保存到 `artifacts/vision_lab/` 下的会话或验收目录，至少包含：

- `calibration.json`
- `calibration_acceptance.json`
- 标定原始帧
- 标定叠加图
- 配置快照

提交时记录 CoppeliaSim 版本、场景哈希和运行日期。

## 人工验收点

教师现场抽查：

1. 学生能解释为什么需要第四个独立验证点；
2. 能从矩阵符号判断坐标轴方向；
3. 能识别“数值误差合格但点序错误”的假通过；
4. 能说明仿真矩阵为什么不能直接复制到海康相机；
5. 能独立找到并保存本次标定证据。
