# 实验四：CoppeliaSim 物体分类

## 实验任务

在完成实验三标定后，从虚拟相机画面识别六个彩色几何物体，计算其世界坐标，控制六轴机械臂和吸盘逐个搬运到红、绿、蓝、黄分类区，并验证每次释放位置。

## 实验入口

先完成实验三，再在同一 PyQt 教学界面执行分类任务：

```powershell
powershell -ExecutionPolicy Bypass -File tools\vision_lab\run_pyqt.ps1
```

教师也可运行自动验收基线：

```powershell
powershell -ExecutionPolicy Bypass -File tools\vision_lab\run_acceptance.ps1
```

## 原理

任务链路为：

1. 相机获取新帧；
2. HSV 颜色与轮廓形状识别；
3. 仿射矩阵把像素中心转换为世界 X/Y；
4. 安全门控生成“抬升—水平移动—下降”路径；
5. 吸盘把最近且符合条件的物体挂到 `/BLX_tool_suction`；
6. 到目标分类区释放；
7. 用物体中心是否落在目标区域内生成验证证据；
8. 下一物体重新取帧，避免使用搬运前的旧坐标。

## 操作步骤

1. 启动界面并确认实验三标定状态为合格。
2. 点击“识别”，核对六个物体的颜色、形状、像素中心和世界坐标。
3. 选择连续模式或单步模式。
4. 启动分类，观察每个对象的状态事件。
5. 检查水平运动是否始终发生在安全高度。
6. 检查吸盘开启后物体是否随 TCP 移动。
7. 检查吸盘关闭后物体是否落入对应颜色区域。
8. 观察第二个及后续物体是否重新取帧。
9. 任务结束后核对完成数、吸附数、释放数和正确区域数。
10. 保存事件日志、关键帧和最终报告。

## 完成条件

- 识别并处理 6 个对象；
- `objects_completed = 6`；
- `attach_success = 6`；
- `release_success = 6`；
- `correct_zone = 6`；
- 无低于安全高度的水平搬运；
- 每个对象至少保存抓取前和释放后的关键帧；
- 最终状态为 `PASS`，且没有被忽略的错误事件。

## 常见错误

- 提示“Classification requires a completed calibration”：先完成实验三并保存标定。
- 吸附失败：检查识别坐标、抓取 Z 和物体是否仍属于 Pickables。
- 同一对象被重复识别：确认每轮重新取帧，并排除已进入分类区的对象。
- 机械臂越界：检查世界坐标是否在 X 20–140 mm、Y -90–90 mm、Z 10–140 mm 范围内。
- RX/RY/RZ 修改无效：当前仿真为 position-only，姿态参数被忽略。
- 场景物体已经被移动：重新加载 `BL23_vision_lab.ttt` 后再开始。

## 仿真与真机差异

仿真吸附通过父子关系实现，不模拟真空建立时间、漏气、软管拖拽和物体表面粗糙度。真实机械臂必须重新确定 TCP、抓取 Z、释放高度和速度；还必须验证急停、碰撞风险和吸盘气路。仿真区域判定也不能替代真实物体是否稳定落位的人工观察。

## 结果保存

自动验收默认在 `artifacts/vision_lab/final/closed-loop/` 生成：

- `acceptance.json`
- `classification_acceptance.json`
- `events.jsonl`
- 抓取前、吸附后、释放后的关键帧
- `config_snapshot.json`
- 场景和厂家来源哈希

学生手工实验应使用独立输出目录，避免覆盖同组其他同学的证据。

## 人工验收点

教师现场抽查：

1. 学生能解释为何每个对象都要重新取帧；
2. 能指出安全高度和水平移动门控；
3. 能从事件日志定位一次吸附或放置失败；
4. 能说明仿真吸附与真实真空吸盘的差异；
5. 能在暂停、继续、复位和急停语义之间作出正确选择；
6. 能根据真机清单规划低速空跑、单物体和多物体验证。
