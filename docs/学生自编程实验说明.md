# 学生自编程实验说明

本实验让学生在 CoppeliaSim 中编写并验证受控的机械臂任务程序，再把已经
验证过的任务逻辑带到实验室进行低速真机复核。当前自动化证据只覆盖仿真；
海康相机和真实机械臂仍为 `PENDING_HARDWARE`，不得把仿真 `PASS` 写成
真机验收通过。

## 学习目标

完成实验后，学生应能够：

1. 从课程模板复制出自己的 UTF-8 Python 程序，并正确实现
   `def main(ctx):`；
2. 使用教学 SDK 完成回零、世界坐标运动、TCP 读取、吸盘控制、日志、
   等待和单步检查点；
3. 解释 X、Y、Z、速度和等待时间的单位，以及 `safe_z` 安全高度规则；
4. 在 PyQt 页面完成打开、保存、检查、运行、暂停、继续、下一步、停止和
   复位场景；
5. 使用 CLI 或 PowerShell 完成静态检查与在线仿真运行；
6. 根据稳定错误码定位故意设置的语法、安全和运行错误；
7. 读取一次运行的源码、哈希、命令、事件和汇总证据；
8. 说明仿真通过与真实海康相机、真实机械臂验收之间的边界。

## 实验前提

- Windows PowerShell；
- CoppeliaSim，默认目录为 `E:\CoppeliaSim`；
- 项目完整副本和 `.git` 均位于内置 C 盘；
- 项目根目录已有 `.venv-vision`；
- 场景文件为
  `simulation\vision_lab\BL23_vision_lab.ttt`；
- 默认 ZMQ Remote API 地址为 `127.0.0.1:23000`。

必须保留引号和 `-LiteralPath`。

```powershell
Set-Location -LiteralPath $ProjectRoot
```

首次使用先执行：

## 从模板复制程序

不要直接修改课程模板。先复制一份，再编辑副本：

```powershell
Set-Location -LiteralPath $ProjectRoot
New-Item -ItemType Directory -Force `
  ".\student_programs\work" | Out-Null
Copy-Item -LiteralPath `
  ".\student_programs\templates\basic_motion.py" `
  -Destination ".\student_programs\work\学号-basic_motion.py"
```

最小程序结构如下：

```python
def main(ctx):
    ctx.log("实验开始")
    ctx.robot.home()
    ctx.log("实验结束")
```

模块顶层只允许安全的定义和常量，不要在顶层调用机器人动作。入口必须是
同步函数 `main(ctx)`，不能遗漏、重复或改成其他参数签名。

## 教学 SDK

位置一律使用世界坐标，单位为 `mm`；速度使用平台配置的教学速度数值；
`ctx.sleep` 的单位为秒。当前接口是 position-only，不接收 RX/RY/RZ。

| API 签名 | 作用与返回值 | 单位和注意事项 |
|---|---|---|
| `ctx.robot.home() -> None` | 回到教学准备位 | 最终 TCP 应回到场景的 teaching-ready pose |
| `ctx.robot.move_world(x_mm, y_mm, z_mm, *, speed) -> None` | 移动 TCP 到世界坐标 | X/Y/Z 为 `mm`；`speed` 必须显式给出 |
| `ctx.robot.pose() -> tuple[float, float, float]` | 读取当前 TCP `(x, y, z)` | 三个值均为世界坐标 `mm` |
| `ctx.tool.on() -> None` | 开启吸盘 | 只允许在配置的低位抓取高度使用 |
| `ctx.tool.off() -> None` | 关闭吸盘 | 停止或失败清理时平台也会强制关闭 |
| `ctx.log(message) -> None` | 写入教学日志和事件证据 | `message` 会转换为字符串且受长度限制 |
| `ctx.sleep(seconds) -> None` | 可取消的有界等待 | 单位为秒，默认单次不超过 5 秒 |
| `ctx.checkpoint(label) -> None` | 建立带标签的教学单步点 | 暂停模式下由“下一步”逐条放行 |

示例：

```python
def main(ctx):
    ctx.log("移动到安全高度")
    ctx.robot.home()
    ctx.checkpoint("回零后检查")
    ctx.robot.move_world(100, 60, 120, speed=15)
    pose = ctx.robot.pose()
    ctx.log(f"当前 TCP={pose}")
    ctx.robot.home()
```

静态检查会拒绝已列入限制表的危险模块，例如 `socket`、`subprocess`、
`ctypes`、底层 CoppeliaSim 客户端和平台内部后端；它不是“所有系统模块
一律禁止”的白名单，`os` 当前允许导入。学生仍不得借此访问课堂任务之外
的网络、进程或文件。该检查只适用于可信课堂代码，**不是恶意代码安全
沙箱**，教师运行前仍须审查源码。

## 安全规则

默认教学工作空间为：

- X：`20..140 mm`；
- Y：`-90..90 mm`；
- Z：`10..140 mm`；
- 安全高度 `safe_z`：`100 mm`；
- 吸盘开启高度：Z 不高于 `35 mm`；
- 速度范围：`1..30`；
- 总运行时间：不超过 60 秒；
- 命令总数：不超过 200；
- 单个命令超时：10 秒；
- 单次 `ctx.sleep`：不超过 5 秒。

`100 mm` 是平台禁止低位横移的安全边界；`pick_and_place.py` 故意使用
`safe_z = 110`，为仿真 IK 反馈误差留出 10 mm 高度余量。模板在抓取点和
放置点的下探前、抬升前都调用 `ctx.robot.pose()`，使用返回的实际 X/Y
做严格竖直升降。不得把路径拆成连续 0.1 mm 或 0.5 mm 的低位横移来绕过
安全门，这些小步仍会被拒绝。

当当前 TCP 低于 `safe_z` 时，只能竖直升降，不能直接做水平运动。标准
路径是：

1. 先保持 X/Y 不变，竖直上升到 `safe_z` 或更高；
2. 在安全高度水平移动到目标上方；
3. 再保持 X/Y 不变，竖直下降；
4. 只有到达抓取高度后才允许 `ctx.tool.on()`；
5. 抓取后先竖直抬升，再进行水平搬运。

不要通过提高速度、扩大工作空间或删除安全检查来“修复”学生程序。

## PyQt 操作流程

在项目根目录启动教学界面：

```powershell
powershell -ExecutionPolicy Bypass -File `
  ".\tools\vision_lab\run_pyqt.ps1"
```

进入“学生编程”页后按以下顺序操作：

1. **打开程序**：选择自己的 `.py` 文件并载入编辑器。
2. **保存**：写回当前文件；**另存为**会先成功写入候选文件，再切换当前
   文件身份，写入失败不会丢失原路径或编辑内容。
3. **检查代码**：执行 UTF-8、语法、入口、导入和顶层调用检查。只有
   `PASS` 后“运行”才可用。
4. **运行**：保存、再次检查并启动独立学生进程。界面显示状态、当前命令、
   命令数、运行时间、TCP 和证据目录。
5. **暂停**：在当前命令完成后暂停继续取命令。
6. **继续**：从暂停状态恢复连续运行。
7. **下一步**：在暂停状态放行一条命令；建议程序中使用
   `ctx.checkpoint(label)` 标记观察点。
8. **停止**：异步请求取消。停止过程中不要关闭 CoppeliaSim 或拔掉通信
   连接，等待状态进入 `CANCELLED`。
9. **复位场景**：只在 `PASSED`、`FAILED` 或 `CANCELLED` 后可用。复位
   完成后，终态期间暂存的新源码才会重新载入并检查。

运行时文件操作和编辑器会被禁用；终态允许编辑，但新文件在复位同步前
不能复用上一次的检查结果。

## CLI 与 PowerShell 操作

先做不连接 CoppeliaSim 的静态检查：

```powershell
Set-Location -LiteralPath $ProjectRoot
& ".\.venv-vision\Scripts\python.exe" `
  -m vision_platform.cli student-validate `
  --program ".\student_programs\work\学号-basic_motion.py"
```

启动或复用 CoppeliaSim，并运行学生程序：

```powershell
Set-Location -LiteralPath $ProjectRoot
powershell -ExecutionPolicy Bypass -File `
  ".\tools\vision_lab\run_student_program.ps1" `
  -Program ".\student_programs\work\学号-basic_motion.py" `
  -OutputDir ".\artifacts\vision_lab\student-runs"
```

教师或开发者需要直接运行在线 pytest 时，先启动并验证正式 BL23 listener：

```powershell
powershell -ExecutionPolicy Bypass -File `
  ".\tools\vision_lab\launch_coppeliasim.ps1"

& ".\.venv-vision\Scripts\python.exe" -m pytest `
  ".\tests\test_acceptance\test_coppeliasim_student_program.py" `
  -m coppeliasim -q
```

在线 fixture 不会启动或终止 CoppeliaSim；缺 listener 或场景错误会直接
FAIL 并给出上述启动命令。`run_student_program.ps1` 只在本次确实新启动
CoppeliaSim 时记录 `StartedByScript`、PID 和路径，并在退出时精确回收；
复用教师或学生已打开的 listener 时不会终止它。

需要直接调用 CLI 时，仍必须明确使用仿真后端：

```powershell
& ".\.venv-vision\Scripts\python.exe" `
  -m vision_platform.cli student-run `
  --program ".\student_programs\work\学号-basic_motion.py" `
  --robot sim `
  --scene ".\simulation\vision_lab\BL23_vision_lab.ttt" `
  --host 127.0.0.1 `
  --port 23000 `
  --output ".\artifacts\vision_lab\student-runs"
```

退出码 0 只代表本次仿真学生程序为 `PASS`；静态检查失败返回 2，其他
运行失败返回 1。在线测试被跳过不属于 `PASS`。

## 运行证据

每次启动会在 `artifacts\vision_lab\student-runs` 下创建独立运行目录：

| 文件 | 内容 |
|---|---|
| `source.py` | 本次实际执行的源码副本 |
| `source.sha256` | 源码 SHA-256，用于证明执行后未被替换 |
| `manifest.json` | 运行 ID、原路径、源码哈希、后端和硬件状态 |
| `commands.jsonl` | 每条 SDK 命令、参数、结果和时间 |
| `events.jsonl` | 状态切换、日志、停止和清理事件 |
| `summary.json` | 最终状态、命令数、末端位置、安全违规和错误 |

检查时应确认：

- `source.py` 与提交源码一致；
- `source.sha256`、`manifest.json` 和 `summary.json` 中的哈希一致；
- `commands.jsonl` 与 `events.jsonl` 不是空文件；
- `summary.json.status` 为预期状态；
- `hardware_status` 仍为 `PENDING_HARDWARE`，不能改写为硬件通过。

## 故意失败练习

每次只引入一个错误，记录稳定错误码，再恢复正确代码。运行时安全错误只在
CoppeliaSim 仿真中执行，不要带到真实机械臂。

1. **删除入口函数**：删除 `def main(ctx):`。静态检查应返回
   `MAIN_MISSING`。
2. **导入禁止模块**：在文件中加入 `import socket`。静态检查应返回
   `IMPORT_NOT_ALLOWED`。
3. **越出工作空间**：调用
   `ctx.robot.move_world(200, 0, 120, speed=15)`。运行应返回
   `TARGET_OUT_OF_WORKSPACE`。
4. **速度越界**：把速度改为 `speed=31`。运行应返回
   `STUDENT_SPEED_INVALID`。
5. **高位开启吸盘**：在 Z=`120 mm` 时调用 `ctx.tool.on()`。运行应返回
   `STUDENT_TOOL_HEIGHT_INVALID`。
6. **等待超限**：调用 `ctx.sleep(6)`。运行应返回
   `STUDENT_SLEEP_INVALID`。

补充练习：删除冒号制造语法错误，应得到 `SYNTAX_ERROR`；取消正在运行的
程序，应得到受控的 `STUDENT_PROGRAM_CANCELLED`，而不是关闭或杀死
CoppeliaSim。

## 仿真与真机边界

仿真可以验证程序结构、世界坐标路径、安全门控、状态机、证据生成和
CoppeliaSim 中的末端位置，但不能证明以下事项：

- 海康相机已枚举、MVS 驱动正常、曝光/触发/帧率合格；
- 仿真标定参数可直接用于真实相机；
- 真实机械臂 TCP、零点、方向和工作空间与仿真一致；
- 实体碰撞、急停、吸盘气路、密封和负载已经验收；
- position-only 路径已经覆盖真实末端 RX/RY/RZ 姿态要求。

学生运行器用于课堂可信代码的受控执行，**不是恶意代码安全沙箱**。它会
阻止已知危险导入和任意命令，但不能替代操作系统级隔离、账号权限和人工
代码审查。

本机未连接海康相机和真实机械臂。相关结论必须保持
`PENDING_HARDWARE`，之后按照《仿真转真机验证清单》完成急停、低速空跑、
单物体和多物体测试，才能形成硬件验收记录。

## 常见问题

- **“运行”不可用**：先保存并执行“检查代码”，确认没有暂存但未同步的
  终态文件。
- **停止后不能再次运行**：先等待进入终态，再执行“复位场景”和检查。
- **端口 23000 无响应**：检查 CoppeliaSim 是否运行、ZMQ 插件是否加载；
  不要直接结束不属于本脚本启动的 CoppeliaSim 进程。
- **TCP 与预期不一致**：确认程序最后调用 `ctx.robot.home()`，并检查
  `summary.json.last_pose_mm`。
- **证据目录缺文件**：该次运行不能作为完整提交，保留控制台错误并重新
  运行，不要手工伪造证据。
