# 视觉仿真实训平台使用说明

## 1. 平台用途

本平台把实验三“视觉标定”和实验四“物体分类”迁移到 CoppeliaSim。学生先在虚拟相机、OpenR6 六轴本体和吸盘上完成代码调试，再把同一任务层代码切换到实验室真实机械臂与海康相机。

仿真已经覆盖：

- CoppeliaSim 虚拟相机取帧；
- 三点仿射标定与独立验证点；
- 颜色、形状识别；
- 六个物体的吸附、搬运、释放和区域判定；
- PyQt 教学控制台；
- CoppeliaSim 内嵌 simUI 状态面板；
- 自动化验收证据。

本机没有连接海康相机和真实机械臂，因此所有硬件项仍为 `PENDING_HARDWARE`。

## 2. 模型说明

运行场景使用 `openr6_arm.7z` 对应的正确七段机械臂本体作为关节外观。该模型与项目内正式 OpenR6 网格逐文件哈希一致；场景副本中修正了 `link6` 的 10 倍尺寸错误，并在既有 `/BLX_tool_suction` TCP 上增加吸盘适配器、连接杆和吸盘杯。

用户指定的 BL23 厂家 STEP 仍保留完整来源哈希和 141 个实体审计，但不再作为运行外观。原因是厂家 STEP 缺少可信的关节装配映射，既有分段记录还证明 link3–link4 存在硬断裂；继续逐段包围盒对齐会复现悬空与重叠。

## 3. 环境准备

要求：

- Windows PowerShell；
- CoppeliaSim，默认安装在 `E:\CoppeliaSim`；
- 项目根目录下 `.venv-vision`；
- 已执行 `pip install -r requirements-vision.txt`；
- ZMQ Remote API 端口默认使用 `23000`。

首次使用时，在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File tools\vision_lab\bootstrap.ps1
```

该命令创建 `.venv-vision`、安装完整自动验收环境，并连接本机 CoppeliaSim 的 ZMQ Python 客户端。只运行课堂标定、识别和分类功能而不执行完整测试或场景重建时，可选加 `-SkipCad` 跳过 CAD 包。

若 CoppeliaSim 不在默认位置：

```powershell
$env:COPPELIASIM_ROOT = "D:\Apps\CoppeliaSim"
```

## 4. 一条命令启动

在项目根目录执行。

启动仿真教学界面：

```powershell
powershell -ExecutionPolicy Bypass -File tools\vision_lab\run_pyqt.ps1
```

仅处理教材中的真实历史图片：

```powershell
powershell -ExecutionPolicy Bypass -File tools\vision_lab\run_replay_demo.ps1
```

运行完整自动化验收：

```powershell
powershell -ExecutionPolicy Bypass -File tools\vision_lab\run_acceptance.ps1
```

只打开 CoppeliaSim 场景：

```powershell
powershell -ExecutionPolicy Bypass -File tools\vision_lab\launch_coppeliasim.ps1
```

直接运行在线 pytest 时，必须先执行上面的启动命令，等待脚本完成真实 RPC、
正式 BL23 场景和两个哨兵检查，再执行：

```powershell
.\.venv-vision\Scripts\python.exe -m pytest `
  tests\test_acceptance\test_coppeliasim_calibration.py `
  tests\test_acceptance\test_coppeliasim_classification.py `
  tests\test_acceptance\test_coppeliasim_student_program.py `
  -m coppeliasim `
  --coppelia-host 127.0.0.1 `
  --coppelia-port 23000 `
  -q
```

非默认实例必须在启动和 pytest 两处使用同一端点，例如启动脚本传
`-Port 23001` 时，pytest 同时传 `--coppelia-port 23001`。pytest 解析
优先级为显式参数、`COPPELIA_HOST`/`COPPELIA_PORT`、最后默认
`127.0.0.1:23000`。

在线 fixture 不会启动或终止 CoppeliaSim；缺少 listener 或场景错误会直接
FAIL 并提示 `launch_coppeliasim.ps1`。`run_acceptance.ps1`、
`run_student_program.ps1` 和 `run_pyqt.ps1` 只回收各自
`StartedByScript=true` 且启动身份一致的进程，不会结束复用的用户进程。
launcher 返回 `ProcessId`、规范化 `ProcessPath` 和启动时冻结的
`ProcessStartTimeUtcTicks`。四个入口共用
`tools\vision_lab\process_ownership.ps1`；清理前会严格比较该三元组，
路径或启动时间无法读取、任一字段不一致、退出等待超时或原三元组仍存活
都会明确失败。身份不匹配时不会调用停止。完整验收先完成清理，再写
汇总；因此清理失败会得到 `FAIL` 和非零退出码，而不会留下虚假的 PASS。
launcher 会先规范化 `CoppeliaRoot` 和 executable，因此
`E:\CoppeliaSim\.` 与 `E:\CoppeliaSim` 使用同一进程身份。清理直接针对
已经验证的 Process 对象；停止后的 survivor 仍按原三元组判断，不会在
PID 被复用后误停新进程。极端情况下，若 CoppeliaSim 已由
`Start-Process` 启动、但启动时间等身份尚未成功读取，launcher 会通过
`Stop-StartedProcessObject` 只停止 `Start-Process` 返回的原始 Process
对象并等待退出，不会查询或按这个未验证 PID 查杀。

## 5. 建议教学流程

1. 教师先运行完整自动化验收，确认软件与场景基线。
2. 学生启动 PyQt 教学界面，检查连接状态和虚拟相机画面。
3. 按《实验三-CoppeliaSim视觉标定》完成标定。
4. 保存标定参数并检查 RMS、最大误差和独立验证点。
5. 按《实验四-CoppeliaSim物体分类》完成六物体分类。
6. 检查每个物体的识别结果、世界坐标、吸附/释放和目标区域。
7. 使用《仿真转真机验证清单》在实验室逐项切换到海康相机和真实机械臂。

## 6. 学生自编程

学生可从
`student_programs\templates\basic_motion.py` 复制程序，通过受控教学
SDK 操纵 CoppeliaSim 中的机械臂。完整 API、`safe_z` 规则、PyQt 状态流、
故意失败练习和提交要求见
[学生自编程实验说明](学生自编程实验说明.md)。
抓放模板使用 110 mm clearance；每次在抓取点或放置点下探、抬升前，先
读取实际 TCP X/Y，再做严格竖直升降，平台不会为 IK 误差放宽低位横移
安全门。

先做静态检查：

```powershell
.\.venv-vision\Scripts\python.exe -m vision_platform.cli student-validate `
  --program "student_programs\templates\basic_motion.py"
```

再启动或复用 CoppeliaSim 运行程序：

```powershell
powershell -ExecutionPolicy Bypass -File `
  tools\vision_lab\run_student_program.ps1 `
  -Program "student_programs\templates\basic_motion.py"
```

也可在 PyQt 的“学生编程”页完成打开、保存、检查、运行、暂停、继续、
下一步、停止和复位场景。每次运行的源码、SHA-256、命令、事件和汇总证据
保存在 `artifacts/vision_lab/student-runs`。学生程序仍受工作空间、
`safe_z`、吸盘高度、速度、时长和命令数量限制，不能绕过底层安全门控。

学生运行器面向课堂可信代码，不是恶意代码安全沙箱。仿真程序 `PASS`
只证明软件和当前 CoppeliaSim 场景达到自动化条件；海康相机、真实机械臂、
急停、气路和实体抓取仍为 `PENDING_HARDWARE`。

## 7. 关键接口约束

- 坐标控制为 `position-only`。
- X、Y、Z 使用世界坐标毫米。
- RX/RY/RZ 为兼容接口保留，但仿真 IK 忽略它们。
- 机械臂基座不翻转。
- 建议工作半径不超过 150 mm。
- 仿真相机的标定参数不能直接用于真实海康相机。
- 仿真抓取成功不能替代真实 TCP、抓取 Z、吸盘密封和急停验收。

## 8. 结果位置

默认输出：

- PyQt 过程证据：`artifacts/vision_lab/pyqt-session/`
- replay 识别证据：`artifacts/vision_lab/replay/`
- 学生程序证据：`artifacts/vision_lab/student-runs/`
- 完整自动验收：`artifacts/vision_lab/final/`
- 场景运行报告：`simulation/vision_lab/runtime_verification.json`
- 三视图：`artifacts/vision_lab/robot-views/`

`artifacts/vision_lab/` 默认不进入 Git，学生提交时应按课程要求单独打包。

## 9. 已知限制

- 本阶段不验证海康 MVS 驱动、曝光、触发和真实帧率。
- 本阶段不验证真实机械臂碰撞、急停和吸盘气路。
- 位置 IK 不约束末端姿态。
- 厂家 BL23 STEP 只用于来源审计，不作为可动运行外观。
- 自动化测试通过不等于最终教学效果通过；最终仍需教师按学生操作流验收。

## 10. 最终人工验收

教师应至少确认：

1. 学生能在不修改底层代码的情况下启动场景和界面；
2. 能解释像素坐标到世界坐标的关系；
3. 能独立完成标定并判断误差是否合格；
4. 能完成六物体分类并解释失败事件；
5. 能说明 position-only 与真实末端姿态控制的差异；
6. 到实验室后能按清单完成低速空跑、单物体和多物体验证。
