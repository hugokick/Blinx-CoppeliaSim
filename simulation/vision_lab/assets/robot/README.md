# BL23 STEP-derived robot visuals

The STL files in this directory are generated by
`python -m simulation.vision_lab.import_robot_assets`.

Their only geometry source is the user-selected vendor STEP archive pinned in
`source_manifest.json`. The formal BLX scene, URDF, and meshes are protected
inputs and are never overwritten.

Each generated STL retains millimetre vertices. The scene builder applies the
locally verified direct millimetre-to-metre import factor (`0.001`) and records
all hashes, triangle counts, bounds, watertight status, source tags, and
collision policy in `robot_assets_manifest.json`.

`anchors/` contains one-entity OCP exports used only to align current STEP
segments to the protected BLX joint-frame visuals. They are not historical
v10/v12 candidate meshes. The complete 141-entity mapping remains an audit
record; uncertain internal fasteners and electronics are intentionally omitted
from articulated exterior meshes instead of being assigned to an arbitrary
moving link.
